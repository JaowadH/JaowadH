When I'm not at work, I'm usually spinning up new services in my server rack, building web apps, or playing chess.

### 🔭 What I'm up to lately:
- 💻 Building a full-stack React and Node.js platform for friends and family (complete with a custom pet media feed).
- 🖥️ Tinkering with my homelab. I run a multi-node **Proxmox** cluster, route my network through **pfSense**, and self-host services using Docker and Caddy.
- ☕ Writing a Java-based Discord bot for Minecraft server management.
- ♟️ Competing in local over-the-board classical chess tournaments.
